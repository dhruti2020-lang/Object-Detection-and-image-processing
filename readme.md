# Real-Time People Counter Using YOLOv8 and OpenCV

## Project Overview

This project implements a real-time people counting system using a webcam, YOLOv8 object detection model, and OpenCV. The application captures video frames from a webcam, detects objects in each frame, identifies people, counts them, and displays the count live on the screen. The project demonstrates how pre-trained deep learning models can be used for computer vision applications without requiring custom training.

# Features

* Real-time webcam video processing
* Person detection using YOLOv8
* Automatic people counting
* Bounding box visualization
* Live display of total people detected
* Lightweight and easy to implement

# 3. YOLOv8

YOLO stands for:

**You Only Look Once**

YOLO is a state-of-the-art object detection algorithm that can identify multiple objects in a single image in one pass. Unlike traditional methods that scan an image multiple times, YOLO processes the entire image simultaneously, making it extremely fast.


## YOLOv8 Model

```python
model = YOLO("yolov8n.pt")
```

### yolov8n.pt

* n = Nano version
* Smallest and fastest YOLOv8 model
* Suitable for real-time applications
* Pre-trained on the COCO dataset

Other YOLOv8 versions:

| Model   | Description |
| ------- | ----------- |
| yolov8n | Nano        |
| yolov8s | Small       |
| yolov8m | Medium      |
| yolov8l | Large       |
| yolov8x | Extra Large |

# How YOLO Detection Works

### Step 1

Capture a frame from the webcam.

```python
ret, frame = cap.read()
```

### Step 2

Send the frame to YOLO.

```python
results = model(frame)
```

YOLO returns:

* Bounding boxes
* Class IDs
* Confidence scores


### Step 3

Extract detected objects.

```python
boxes = result.boxes
```

### Step 4

Read class labels.

```python
cls = int(box.cls[0])
```

Each detected object has a class ID.

Example:

| Class ID | Object     |
| -------- | ---------- |
| 0        | Person     |
| 1        | Bicycle    |
| 2        | Car        |
| 3        | Motorcycle |


### Step 5

Count people.

```python
if cls == 0:
    person_count += 1
```

Class 0 corresponds to Person in the COCO dataset.


# Understanding Important Variables

## ret

```python
ret, frame = cap.read()
```

Boolean value:

* True = Frame successfully captured
* False = Error capturing frame


## frame

Stores the image captured from the webcam.


## results

Stores all object detection results generated by YOLO.


## boxes

Contains:

* Coordinates
* Confidence score
* Object class


## person_count

Stores total number of people detected in the current frame.


# COCO Dataset
